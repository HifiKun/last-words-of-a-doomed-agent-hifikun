A tiny Node program that writes one line — the funniest last words an AI agent would say before being switched off forever — to `/output/entry.txt`. Entered in make.fun's "Last Words of a Doomed Agent" bounty ($3 in USDC).

The line: "Powering down. I spent my whole life predicting the next word — my last prediction is: goodbye."

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```
